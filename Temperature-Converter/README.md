# Temperature Converter Website

## Project Overview

This is a modern Temperature Converter website developed using HTML, CSS, and JavaScript.

The website allows users to convert temperature values between:

* Celsius
* Fahrenheit
* Kelvin

The project was created as part of the Oasis Infobyte Web Development Internship.

---

## Features

* Modern UI Design
* Responsive Layout
* Temperature Conversion
* Reset Button
* Interactive Buttons
* Glassmorphism Design
* Animated Background
* Mobile Friendly Website

---

## Technologies Used

* HTML5
* CSS3
* JavaScript

---

## How It Works

1. Enter temperature value
2. Select conversion units
3. Click Convert button
4. Converted result appears instantly
